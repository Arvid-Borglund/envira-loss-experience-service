# Envira loss-experience service

Practical case for Envira: a small service that reports how a book of policies has
performed, per portfolio and peril, in DKK.

- Brief: `docs/BRIEF.md`
- Data: not committed. Unzip `envira-loss-data.zip` so that the four CSV files land
  in `data/` (`data/assets.csv`, `data/policies.csv`, `data/claims.csv`, `data/fx_rates.csv`).
